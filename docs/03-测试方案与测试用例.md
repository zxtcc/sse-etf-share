# 项目测试方案和测试用例

## 测试范围

- 输入校验。
- 上交所接口解析。
- 查询接口响应。
- 本地 Excel 缓存读写。
- 分页全量更新。
- 页面查询和结果展示。

## 测试用例

| 编号 | 场景 | 输入 | 预期结果 |
| --- | --- | --- | --- |
| TC01 | 正常查询 | `510050`，`2025-09-04` | 返回上证 50 ETF 份额数据 |
| TC02 | ETF 代码格式错误 | `5100`，任意日期 | 返回 400 和格式错误提示 |
| TC03 | 日期格式错误 | `510050`，`20250904` | 返回 400 和日期格式错误提示 |
| TC04 | 无数据日期 | `510050`，周末或无披露日期 | 返回 404 和无数据提示 |
| TC05 | 上交所接口异常 | 模拟网络错误 | 返回 502 和接口失败提示 |
| TC06 | 页面展示 | 正常查询 | 页面展示基金代码、日期和总份额（万份） |
| TC07 | 本地缓存命中 | 已存在 `data/510050.xlsx` 记录 | 单日查询不访问上交所，返回 `source=local` |
| TC08 | 数据汇总 | `2025-09-04` 到 `2025-09-04` | 分页获取全量 ETF 数据并写入各 ETF Excel |
| TC09 | 全量日期跳过 | 重复更新 `2025-09-04` | 不访问上交所，返回跳过 1 天 |
| TC10 | 周末跳过 | 日期区间包含周末 | 周末不请求上交所 |

## 自动化测试

使用 Python 标准库 `unittest` 对 `sse_client.py` 的校验、分页解析逻辑，以及 `storage.py` 的 Excel 存取逻辑做单元测试。
