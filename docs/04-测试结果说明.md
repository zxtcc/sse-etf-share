# 项目最终测试结果说明

## 当前测试结果

已完成接口调研，确认上海证券交易所 ETF 规模页面使用：

- 数据接口：`https://query.sse.com.cn/commonQuery.do`
- 关键参数：`sqlId=COMMON_SSE_ZQPZ_ETFZL_XXPL_ETFGM_SEARCH_L`
- 日期参数：`STAT_DATE`
- 返回字段：`STAT_DATE`、`SEC_CODE`、`SEC_NAME`、`ETF_TYPE`、`TOT_VOL`

已完成自动化测试：

```bash
python3 -m unittest
```

结果：7 个用例全部通过。

已完成接口抽测：

- 输入：ETF 代码 `510050`，日期 `2025-09-04`
- 结果：名称 `上证50ETF华夏`，总份额 `5833506.68` 万份，即 `58335066800` 份
- 首次查询返回 `source=sse`，并写入 `data/510050.xlsx`
- 再次查询同一代码和日期返回 `source=local`

已完成数据汇总抽测：

- 输入：`2025-09-04` 到 `2025-09-04`
- 结果：访问上交所 1 个日期，保存 715 条 ETF 数据，生成 715 个 ETF Excel 文件
